**Tina Linux 常用命令速查（嵌入式小白版）**

> 绝大多数板卡使用 BusyBox 精简版命令，`<cmd> --help` 可快速查看用法；没有的命令可以用替代方案（如 `more` 代替 `less`）。

---

## 文件与查看
- `ls -l` 查看目录（`-a` 显示隐藏，`-h` 人类可读大小）
- `cat file` 看小文件；`head -n 20 file` / `tail -n 20 file`；`tail -f file` 追日志
- `less file`/`more file` 翻页查看大文件
- `grep -n "keyword" file` 在文件中搜索（`-r` 递归目录）
- `find /path -name "*.log"` 按名字查文件

## 编辑与重定向
- `echo "text" > file` 覆盖写入；`>>` 追加
- `tee file` / `tee -a file` 写入同时在终端显示

## 复制 / 移动 / 删除
- `cp src dst`（`-r` 递归目录，`-a` 保留属性）
- `mv old new` 重命名/移动
- `rm file`；`rm -r dir` 删除（谨慎，先确认路径）

## 目录操作
- `pwd` 当前路径
- `cd /path` 切换目录
- `mkdir -p /path/sub` 递归创建目录

## 权限与链接
- `chmod 755 file` 改权限
- `chown user:group file` 改属主
- `ln -s target linkname` 建软链接

## 进程与系统
- `ps`（BusyBox 常用）/ `ps -ef` 查看进程
- `top` 实时 CPU/内存（有 `htop` 更友好）
- `kill PID` 正常结束；`kill -9 PID` 强制结束（慎用）
- `pkill name` / `killall name` 按名结束（视裁剪情况）
- `dmesg | tail -n 50` 看内核日志尾部；`dmesg | grep -i error` 过滤错误
- `free -h` 看内存；`uptime` 看负载
- `df -h` 看分区占用；`du -sh /path` 看目录大小

## 挂载 / 卸载（mount）
- `mount`：查看当前挂载
- 示例：`mount -t vfat /dev/sdX1 /mnt` 将 U 盘等挂载到 `/mnt`
- 卸载：`umount /mnt`（如提示忙，先关闭占用的终端或进程）
- 常见文件系统类型：`vfat`（U盘/TF卡 FAT），`ext4`（Linux分区），`nfs`（网络挂载）

## 网络（视裁剪）
- `ifconfig` 或 `ip addr`：看网卡 IP
- `ping 8.8.8.8`：测试连通
- `route -n` 或 `ip route`：查看路由
- `netstat -anp` 或 `ss -lnpt`：看端口/连接
- `wget URL` 或 `curl URL`：下载/HTTP 测试

## 打包与校验
- `tar -czf out.tgz dir/` 打包压缩；`tar -xzf file.tgz` 解压
- `md5sum file` / `sha256sum file` 校验和

## 日志与调试小技巧
- `tail -f /var/log/messages` 或设备自定义日志路径
- `strace -p PID` 跟踪系统调用（若有）
- `lsmod` / `modprobe` 查看/加载内核模块（若支持）

## BusyBox 特性
- 命令精简，参数可能不全：用 `<cmd> --help` 查看支持的选项
- 缺少 `less/htop/ss` 等时，可用 `more/top/netstat` 替代

## 安全与谨慎
- 避免在根目录使用 `rm -rf`；删除前先 `pwd` 确认路径
- 挂载/卸载前确认设备节点，避免破坏存储
- `kill -9` 仅在普通 `kill` 不生效时使用

cat /proc/mtd 显示板上 NAND/闪存的 MTD 分区表。各列含义：

dev：MTD 设备号（mtdX）。
size：分区大小（十六进制，单位字节）。
erasesize：块擦除大小（十六进制，单位字节，表示这个分区所在芯片的擦除粒度）。
name：分区名。
对当前输出的逐项解释（约数为十进制）：

mtd0 "boot0"：0x00100000 ≈ 1 MB，擦除块 0x40000=256 KB。存放 boot0（BROM 加载的第一阶段）。
mtd1 "uboot"：0x00300000 ≈ 3 MB，擦除块 256 KB。存放 U-Boot。
mtd2 "secure_storage"：0x00100000 ≈ 1 MB，256 KB 擦除。安全存储区（密钥/校验信息等）。
mtd3 "sys"：0x07b00000 ≈ 123 MB，256 KB 擦除。系统大分区（可能包含内核、根文件系统镜像等整包）。
mtd4 "mbr"：0x0003f000 ≈ 258 KB，擦除块同 0x3f000。MBR/分区表元数据区。
mtd5 "boot-resource"：0x00276000 ≈ 2.48 MB，擦除块 0x3f000。启动资源（logo、配置等）。
mtd6 "env"：0x0003f000 ≈ 258 KB，擦除块 0x3f000。U-Boot 环境变量。
mtd7 "env-redund"：同上，为环境变量冗余备份。
mtd8 "boot"：0x009d8000 ≈ 10.3 MB，擦除块 0x3f000。内核/启动分区（常见存放 zImage/uImage）。
mtd9 "rootfs"：0x0191a000 ≈ 25.4 MB，擦除块 0x3f000。根文件系统分区（squashfs/ubifs等）。
mtd10 "UDISK"：0x04d07000 ≈ 77.1 MB，擦除块 0x3f000。用户数据分区（可读写存储）。
