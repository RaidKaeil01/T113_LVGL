# 录音功能说明文档

## 一、功能概述

在全志T113-S3开发板的LVGL应用程序（demo7）中实现了完整的录音功能，包括录音、停止、播放三个核心功能。该功能位于主菜单的"录音"（Recorder）选项中。

---

## 二、硬件平台

- **开发板**: 全志T113-S3 (ARM Cortex-A7 @ 1.2GHz)
- **操作系统**: Tina Linux (基于OpenWrt)
- **显示屏**: 720x1424分辨率，横屏模式
- **音频硬件**:
  - Codec: SUNXI-CODEC (audiocodec)
  - 输入: MIC3 (板载麦克风) → ADC3
  - 输出: 耳机/扬声器

### 3.2 核心功能

#### 1. 录音功能 (`start_btn_event_cb`)
- **录音参数**:
  - 采样率: 48000 Hz
  - 格式: S16_LE (16位小端)
  - 声道数: 1 (单声道)
  - 设备: hw:0,0

- **音频设置**:
  ```bash
  amixer -c 0 cset numid=11 31   # MIC3增益最大
  amixer -c 0 cset numid=8 255   # ADC3音量最大
  amixer -c 0 cset numid=4 63    # 数字音量最大
  ```

- **录音命令**:
  ```bash
  arecord -D hw:0,0 -c 1 -f S16_LE -r 48000 /usr/data/record/voice.wav
  ```

- **实现方式**: 使用`fork()`创建子进程，通过`execlp()`执行arecord命令

#### 2. 停止录音 (`stop_btn_event_cb`)
- 通过`kill`命令终止录音子进程
- 重置录音状态标志
- 更新UI状态显示为"录音已停止"

#### 3. 播放录音 (`play_btn_event_cb`)
- **首次点击**: 开始播放录音
- **再次点击**: 停止当前播放（支持随时中断）

- **音频设置**（优化后降低音量避免杂音）:
  ```bash
  amixer -c 0 cset numid=17 5       # 耳机音量设为5
  amixer -c 0 cset numid=5 200,200  # DAC音量设为200
  amixer -c 0 cset numid=30 on      # 启用耳机输出
  amixer -c 0 cset numid=31 on      # 启用扬声器
  ```

- **播放命令**:
  ```bash
  aplay /usr/data/record/voice.wav
  ```

### 3.3 状态管理

```c
static bool is_recording = false;   // 录音状态
static bool is_playing = false;     // 播放状态
static pid_t record_pid = -1;       // 录音进程ID
static pid_t play_pid = -1;         // 播放进程ID
```

### 3.4 文件存储

- **录音目录**: `/usr/data/record/`
- **录音文件**: `/usr/data/record/voice.wav`
- **自动创建**: 首次录音时自动创建目录（权限755）

## 五、测试验证

### 5.1 命令行测试（验证硬件正常）

```bash
# 录音5秒
arecord -D hw:0,0 -c 1 -f S16_LE -r 48000 -d 5 /tmp/test.wav

# 播放录音
aplay /tmp/test.wav
```

### 5.2 界面测试流程

1. 启动demo7程序: `/data/demo7`
2. 进入主菜单，选择"录音"（Recorder）
3. 点击开始按钮，对着麦克风说话
4. 点击停止按钮，结束录音
5. 点击播放按钮，听取录音内容
6. 再次点击播放按钮，可随时停止播放

### 5.3 已知问题及解决方案

#### 问题1: 播放杂音过大
**原因**: 初始版本音量设置过大（耳机音量7，DAC音量255）  
**解决**: 降低播放音量（耳机音量5，DAC音量200）

#### 问题2: 播放无法中断
**原因**: 初始版本不支持播放中途停止  
**解决**: 添加再次点击播放按钮停止播放的功能

## 八、技术要点

### 8.1 进程管理
- 使用`fork()`创建子进程执行音频命令
- 父进程保存子进程PID用于终止控制
- 通过`kill`命令终止子进程

### 8.2 音频参数调优
- **录音增益**: 根据实际环境调整MIC3增益（numid=11）
- **播放音量**: 避免过大导致失真杂音（耳机5，DAC 200）
- **采样率**: 48kHz适合语音录音

### 8.3 文件系统
- 录音文件存储在`/usr/data/record/`目录
- 每次录音覆盖`voice.wav`文件
- 可扩展为多文件管理（添加时间戳命名）
