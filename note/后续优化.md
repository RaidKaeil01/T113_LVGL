📸 推荐摄像头模组
1️⃣ OV5640 DVP / Parallel Camera Module（5MP）

该系列是最常见、最成熟的 并行 DVP 摄像头模组：

🔹 5MP 分辨率（2592×1944 最高）
🔹 支持 YUV422、RAW8/10、RGB565/444/555 等输出格式
🔹 支持 SCCB/I²C 控制（用于配置分辨率、曝光等）

常见型号 / 来源：

OV5640 DVP 5MP Standard Camera Module（通用） – 5MP 高分辨率，适合工业/视觉应用

OV5640 DVP 5MP Camera Module (RobotShop / Camemake) – 10-bit DVP 输出，可降级为 8-bit，非常适合支持标准 8-bit 采集的 SoC

OV5640 Fixed-Focus / Auto-Focus 模组（KLT-B1PF / ST-OV5640） – 具备自动对焦功能，适合需要动态对焦的应用（可选）

📌 推荐理由：

📍 最成熟、体量最大的 5MP 摄像头模组

📍 输出兼容 8-bit DVP / Parallel CSI，可与 T113 的接口匹配

📍 软件支持良好，社区和示例代码多（比如 T113 平台已有 OV5640 适配教程）

👉 如果你需要 高分辨率（1080p 或更高）的图像采集，5MP OV5640 是目前最稳妥的选择。

2️⃣ 2MP OV2732 或 GC2145 DVP Camera Module

如果你的项目对分辨率/带宽要求不高，或者追求 更轻量、低功耗 可以考虑：

OV2732 2MP Parallel + MIPI 模组 – 1080p@60fps 输出，接口包含 DVP 和 MIPI（低端选择）

GC2145 DVP 2MP Camera Module（OV2640 替代） – 2MP (UXGA)，输出格式多样（YUV422、RGB565、RAW），体积小、容易集成

📌 推荐理由：

📍 分辨率适中（1080p/2MP）更易通过 8-bit 并行 CSI 处理

📍 容易稳定采集，不容易出现带宽不足的问题

📍 很多 DVP 模组都有成熟的 Linux / MCU 驱动参考

👉 如果你的应用是 实时视频处理、低延迟采集（比如监控、机器人视觉），可以优先考虑这个档位。
